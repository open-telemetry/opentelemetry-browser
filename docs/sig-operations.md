# Browser SIG Operations

This document includes processes and conventions used by the Browser SIG to get work done.

## SIG Meetings

You can find all the SIG meetings on the main [OpenTelemetry Community](https://github.com/open-telemetry/community/tree/main) page.

For this group, here are the relevant SIG meetings to attend:

| Name | Meeting Time | Meeting Invites Group | Slack Channel | Details |
|------|--------------|-----------------------|---------------|---------|
| Client Instrumentation | Every other Tuesday at 09:00 PT | [calendar-client-side](https://groups.google.com/a/opentelemetry.io/g/calendar-client-side) | [#otel-client-side-telemetry](https://cloud-native.slack.com/archives/C0239SYARD2) | [Details](./sigs.md#client-instrumentation) |
| Browser | Thursday at 8:30 PT | [calendar-browser](https://groups.google.com/a/opentelemetry.io/g/calendar-browser) | [#otel-browser](https://cloud-native.slack.com/archives/C093P0AMP0T) | [Details](./sigs.md#browser) |

Client Instrumentation is a cross cutting group for client-side telemetry. This group focuses on semantic conventions and other cross cutting concerns for client-side telemetry like session management.

Browser is the main implementation SIG meeting focused on issues related to collecting telemetry for web applications.
